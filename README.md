# Strangers of Nowhere Far Away

**SoNFA** — Action MOBA / RTS. Initial prototype: web. Release platforms and date: TBA.

Status: design bootstrap only; no playable build, dependency installation or CI exists yet.

## Accepted foundation

- Three.js + TypeScript, browser execution for prototypes and alpha builds.
- Touch on phones/tablets, gamepad and mouse/keyboard are first-class input targets.
- Console release is an aspiration requiring separate platform work; gamepad support alone is not console support.
- Development should take place in the owner's public GitHub repository. Repository visibility is public by user approval. Deployment remains a separate task.
- The user directs, playtests and gives feedback primarily through conversation; the assistant implements and documents changes.

See [game direction](docs/GAME-DIRECTION.md), [plan](docs/PLAN.md), [status](docs/STATUS.md), [decisions](docs/DECISIONS.md) and [debug workflow](docs/DEBUG.md).

Repository: `frishtx/SoNFA`, public by user approval. The full game title is retained here; GitHub repository names do not use spaces.

No open-source license is assigned by this bootstrap. External asset provenance and usage permissions must be tracked before distribution.
