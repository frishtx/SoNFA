# ورود سریع به دیباگ

گزارش دستیار: مشکل در یک جمله؛ build سالم و مسئله‌دار؛ انتظار/واقعیت؛ قدم‌های بازتولید؛ شواهد و فرضیه‌ها؛ فقط یک اقدام مشخص از کاربر؛ قدم بعدی و rollback.

گزارش پیشنهادی از گوشی: build، نوع ورودی، حرکت انجام‌شده، انتظار، اتفاق واقعی. ضبط صفحه اختیاری است. دستیار به گوشی دسترسی خودکار ندارد.

ابزار debug آینده: frame time، شناسهٔ نسخه، seed آزمایش، نمایش اختیاری hitbox و state، آخرین فرمان‌ها بدون اطلاعات حساس، خروجی گزارش و restart سریع. UI بازی عمومی نباید با این ابزار شلوغ شود.
