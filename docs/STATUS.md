# وضعیت فعلی SoNFA

- مخزن عمومی با تأیید کاربر؛ اسناد پروژه ثبت شده‌اند.
- پایه: Three.js + TypeScript؛ پروتوتایپ وب؛ ارائهٔ نهایی TBA.
- runtime، CI و build قابل‌بازی هنوز وجود ندارند؛ تست اجرایی اجرا نشده است.
- اولویت طراحی: خواندن و فریب، سبک شخصی، سقف بالای اجرا همراه مقابله‌پذیری فنی، و مسیر واقعی پیروزی استراتژیک.
- جهت اولیه: [نشست ۰۰۱](sessions/001-competitive-direction.md).
- نقطهٔ ادامهٔ گیمپلی: [نشست ۰۰۲؛ خون، قلمرو و احیا](sessions/002-blood-territory-respawn.md).
- تصمیم باز: ترتیب احیا و ورود به فاز بدون اسپاون پس از تصرف بیس دوم. احیای یک‌باره پیشنهاد دستیار است و تصویب نشده.
- [استک توسعهٔ ایجنت‌محور](STACK.md): تحقیق Astra، MCP و Higgsfield در ۲۰۲۶-۰۹-۱۶. Higgsfield گزینهٔ آزمایشی است؛ نصب و آزمایش آن در پروژه انجام نشده.
- قدم مهندسی بعدی همچنان P1 است: صحنهٔ ساده، حرکت، یک عمل، restart و ورودی مشترک؛ اولویت فعلی گفتگو طراحی مسابقه است.
- ترجیح کاربر: بحث و گزارش بدون جدول، مناسب خواندن روی گوشی.
