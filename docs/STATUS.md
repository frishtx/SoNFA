# وضعیت فعلی SoNFA

- مخزن عمومی با تأیید کاربر؛ اسناد آغاز پروژه ثبت شده‌اند.
- پایه: Three.js + TypeScript؛ پروتوتایپ وب؛ ارائهٔ نهایی TBA.
- runtime، CI و build قابل‌بازی هنوز وجود ندارند؛ تست اجرایی اجرا نشده است.
- اولویت طراحی کاربر: خواندن و فریب، سبک شخصی، سقف بالای اجرا همراه مقابله‌پذیری فنی، و مسیر واقعی پیروزی استراتژیک.
- گزارش تفصیلی: [نشست ۰۰۱](sessions/001-competitive-direction.md).
- تصمیم بعدی: شرط اصلی برد، نقش کیل و یک آبجکتیو فرعی. پیشنهادها هنوز تصویب نشده‌اند.
- معیار پایان جلسهٔ بعد: توصیف یک برد اجرایی و یک برد استراتژیک در قوانین یکسان.
- قدم مهندسی بعدی همچنان P1 است: صحنهٔ ساده، حرکت، یک عمل، restart و ورودی مشترک؛ اولویت فعلی گفتگو طراحی مسابقه است.
