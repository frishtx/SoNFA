# نشست 003 — معماری جهان و تولید
تاریخ: 2026-10-10

## درخواست قطعی کاربر
پژوهش و آماده‌سازی GitHub برای نویسندگی، جهان‌سازی، طراحی و کارگردانی بازی، شخصیت، مکان، شیء و آرتیفکت؛ سپس تبدیل به بازی، داستان، کامیک، تصویرسازی، برند، سایت، شاپ، آنلاین و محتوا. گزارش بدون جدول.

## نتیجه
[معماری استودیو](../studio/README.md)، پژوهش، قالب‌ها، بک‌لاگ و دو پروندهٔ اولیه آماده شد.
روش و مرحله‌بندی، پیشنهاد اجرایی دستیار است؛ انتخاب محتوای جهان و محصول با کاربر باقی می‌ماند.
پژوهش منابع اصلی: MDA، Design Council، Henry Jenkins، GDC، inkle، McCloud، NN/g، GitHub و Khronos. حد بررسی در سند پژوهش ثبت است.
برنامهٔ نشست ۹۰ دقیقه‌ای انعطاف‌پذیر است؛ جلسهٔ تقویمی ایجاد نشده.

## حفظ تصمیم‌های باز
احیای یک‌باره پس از بیس دوم تصویب نشده؛ مسیر طراحی مبارزه محفوظ است.
ظاهر، انگیزه و تاریخچهٔ Richie و Most Wanted بازند.
رابطهٔ دو شخصیت، سبک هنری نهایی، پولی‌بودن خون و تاریخ عرضه تعیین نشده‌اند.

## اجرا و محدودیت
خروجی این نشست اسناد، فهرست محتوا و قالب‌های GitHub است. بازی، سایت، شاپ، سرور، CI و دارایی رسانه‌ای ساخته نشده‌اند؛ تولید هزینه‌دار اجرا نشده.
گام بعد: وعدهٔ احساسی جهان یا یک صحنهٔ Richie برای استخراج آن.
