# معماری جهان و تولید SoNFA
نسخه 0.1 — 2026-10-10. این ساختار، پیشنهاد اجرایی دستیار بر اساس درخواست کاربر است؛ تصویب خودکار لور یا قابلیت‌های محصول نیست.

## مقصد
ساخت یک جهان تألیفی قابل‌گسترش با بازی در مرکز و امکان داستان، کامیک، تصویرسازی، برند، سایت، فروشگاه، پلتفرم آنلاین و محتوای تبلیغاتی. اکنون فقط معماری و آماده‌سازی؛ runtime و محصول منتشرشده نداریم.

## اختیار و وضعیت
کاربر نویسنده، صاحب جهان و مرجع تصمیم خلاقه است. دستیار پژوهش، گزینه‌سازی، کشف تناقض، مشخصات، پیاده‌سازی و ثبت را انجام می‌دهد.
هر گزاره: confirmed / proposed / experimental / open / superseded.
وضعیت تولید جداست: brief / draft / review / approved-for-production / integrated / validated / released.
تأیید روش به معنی تأیید شخصیت، تصویر یا مکانیک نیست. canonical بودن داستان، آماده‌بودن دارایی برای بازی را ثابت نمی‌کند.

## مرزهای جاری
Three.js + TypeScript و وب، پایهٔ قطعی‌اند. نام‌های Richie Town — King of Streets و Most Wanted — The Genocider قطعی؛ بقیه باز.
احیای یک‌باره پس از سقوط بیس دوم هنوز پیشنهاد است؛ این گره در [نشست 002](../sessions/002-blood-territory-respawn.md) حفظ می‌شود.
هیچ رابطهٔ داستانی بین دو شخصیت، هیچ ظاهر، تاریخچه یا محصول پولی با این سند تصویب نمی‌شود.

## اصل راهبری
گسترش جهان از یک نمونهٔ کوچک و منسجم: یک شخصیت محوری، یک مکان، یک شیء، یک کشمکش و یک تعامل قابل‌بازی؛ اندازه و انتخاب نهایی باز است. هر خروجی باید به یک تصمیم یا آزمون کمک کند. مجموعه‌ای از تصاویر زیبا بدون داستان و رفتار، جهان کامل محسوب نمی‌شود.
