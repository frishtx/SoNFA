# قالب‌های تولید
این قالب‌ها برای کپی و تکمیل‌اند؛ خانهٔ خالی را با حدس قطعی پر نکنیم. برای کارهای کوچک فقط فیلدهای مرتبط لازم‌اند.

## سرآیند مشترک
- ID:
- نوع و نام:
- revision / تاریخ:
- وضعیت تصمیم: open | proposed | experimental | confirmed | superseded
- وضعیت تولید: brief | draft | review | approved-for-production | integrated | validated | released
- منبع / تأییدکننده:
- وابستگی‌ها و رسانه‌های مصرف‌کننده:
- مجهولات:
- معیار پذیرش:
- اقدام بعدی:

## کارت جهان/قانون
- جملهٔ قانون:
- امکان / هزینه / محدودیت / استثنا:
- تأثیر بر زندگی روزمره، قدرت و نبرد:
- حقیقت یا باورِ چه کسی:
- نشانهٔ قابل‌مشاهده:
- تضاد با پرونده‌های دیگر:
- آزمایشی که لازم است:

## کارت شخصیت
- نام / لقب / راوی لقب:
- خواسته / مانع / باور / تناقض / خط قرمز:
- انتخاب تعریف‌کننده و هزینه:
- رابطه‌ها با ID و وضعیت:
- فانتزی بازی / افعال / فاصله / ریسک / counterplay:
- سیلوئت / حرکت / ابزار / صدا:
- anchor ثابت تأییدشده:
- متغیر مجاز در تولید:
- ویژگی‌های هنوز نامعلوم:

## کارت مکان/جناح
- موقعیت / ساکنان / منابع / روابط:
- چه کسی قدرت دارد و چرا:
- شکاف داخلی / تغییر تاریخی:
- معماری / ماده / نور / صدا:
- مسیر، دید، ورودی، نقطهٔ هدف و راه فرار:
- واقعهٔ گذشته / رد آن / برداشت بازیکن:
- کاربرد در صحنه و بازی:

## کارت شیء/آرتیفکت
- سازنده / ماده / مقیاس / مالک:
- کارکرد روزمره / ارزش / تاریخ:
- قدرت / هزینه / محدودیت:
- فرسودگی و نشانهٔ داستانی:
- تعامل بازی / نشانهٔ کاربرد / پاسخ:
- مدل، آیکون، صدا و نسخهٔ تبلیغاتی موردنیاز:

## صحنه/کامیک/کارگردانی
- scene ID / event ID / canon revision:
- رسانه، مخاطب و هدف احساسی:
- نقطه‌دید / زمان / مکان / شخصیت‌ها:
- خواسته / مانع / انتخاب / هزینه / تغییر:
- اطلاعاتی که مخاطب می‌گیرد یا نمی‌گیرد:
- بازی: شرط ورود، فعل، trigger و تغییر state:
- کامیک: پنل‌ها، ترتیب خواندن، دیالوگ و گذر زمان:
- ویدئو: shot، blocking، دوربین، مدت و صدا:
- کدام بخش مختص این رسانه است:
- مرور علیت، پیوستگی و خوانایی:

## Brief دارایی
- asset ID / entity ID / revision:
- کاربرد: runtime | comic | concept | brand | web | promotion
- مرجع ثابت و مجوز آن:
- متغیر خواسته‌شده:
- source/export و مشخصات:
- ابزار/مدل/نسخه/تنظیمات/پرامپت:
- بودجهٔ این آزمایش / هزینهٔ واقعی معلوم:
- نام فایل، checksum و محل پایدار:
- معیار فنی / بازبین خلاقه:
- نتیجهٔ ادغام و بررسی دستگاه:
- محدودیت و اصلاح بعدی:

## آزمایش بازی/محصول
- سؤال و فرضیه:
- وضعیت اولیه / نسخه / دستگاه:
- عمل بازیکن:
- نشانهٔ موفقیت و شکست:
- مشاهدهٔ واقعی، جدا از تفسیر:
- نتیجه: حفظ | اصلاح | کنارگذاری | شواهد ناکافی
- هزینه و تصمیم بعد:

## محتوای انتشار
- مخاطب / هدف / پیام:
- hook / شاهد / CTA:
- رسانه / نسبت تصویر / متن / alt:
- canon revision / سطح افشا:
- وضعیت واقعی build یا asset:
- معیار یادگیری / شیوهٔ اندازه‌گیری:
- تأیید انتشار / زمان:
